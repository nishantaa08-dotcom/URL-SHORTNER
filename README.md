# URL Shortner
A backend URL Shortner application built using Nose.js,
Express.js , and MongoDB.

## Features

-User authentication
-URL shortening
-Redirect to Original URL
-Input Validation
-Global Error Handling
-Envirooment Variables
-MongoDB Database

## Technologies Used

-Node.js
-Express.js
-MongoDB
-Session-Id
-Zod

## Installation 

```bash
npm install
```

## Run

```bash
npm run dev
```
